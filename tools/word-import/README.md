# Word 题目文档 → 拾萃导入文件

把按下面格式整理的 Word（.docx）题目文档，转换成可以在“设置 → 导入文件”中导入的 `.json` 文件。

## Word 文档格式约定

- 书名单独一段：`必修一`、`必修二`、`选修一`、`选修二`、`选修三`；跨书内容放在 `综合题` 段落之后。
- 章名单独一段，以 `第N章` 开头。
- 每道题以 `1、`、`2、` …… 开头；题号后的 `（2026B14苏锡常镇一模T16）` 识别为来源：
  - `2026` 为届别，`B14` 为卷子代码（导入后去掉），`T16` 为题号，末尾带 `改` 表示改编；
  - 期初、期末、联考、调研、模拟、段考类来源自动补“高三”；来源含“高二”的题归为高二。
- 选择题：答案写在题干末尾括号里，例如 `（BCD）`，以括号中的答案为准；选项以 `A．` 开头。选项为**红色**表示正确答案，**蓝色**表示曾选错（误选或漏选）。
- 判断题：句末写 `（ ✓ ）` 或 `（ × ）`；同一编号下可以有多条判断（导入为一题多判）。
- 填空题：答案用**红色下划线**标出，曾答错的空用**蓝色下划线**。
- `解析：` 开头的段落为解析，`补充：` 或 `【拓展】` 开头的段落为补充。
- 不是题目的知识整理（没有答案的条目）作为知识笔记导入。

## 使用步骤

需要 Python 3 和 `lxml`（`pip install lxml`）。

```bash
# 1. 解压 Word 文件
mkdir work && cd work && unzip ../题目.docx -d docx && cd ..

# 2. 提取段落、表格和格式
python3 tools/word-import/extract.py work/docx work/blocks.json

# 3. 按题号切分，并生成便于检查的文字版 review.txt
python3 tools/word-import/segment.py work/blocks.json work/items.json work/review.txt 260

# 4. 编辑 mapping.py：为每道题指定主节、本节 tag 和借用的 tag；为笔记指定所属节

# 5. 生成导入文件
python3 tools/word-import/convert.py work/blocks.json work/items.json work/docx/word/media tools/word-import 导入文件.json 检查明细.json
```

转换后，每道题都会标记“tag 待确认”和“难度未评定”（做错过的题为较难，其余为适中）；按内容调整了所在章节或做过特殊处理的题，会带有“导入备注”，可在程序里用“状态”筛选逐一核对。

`mapping.py` 中现有的内容是第一份文档使用的分节和 tag，可作为参考；`convert.py` 中以题号写死的几处特例（如合并、拆分的题）也只针对那份文档，转换新文档时需要相应调整。

转换生成的导入文件和检查明细包含题目内容，请不要提交到本仓库。
