# 拾萃 · 高中生物好题本

一个在本地运行的高中生物好题整理工具，按人教版（2019）必修1 – 选择性必修3 的目录管理题目和知识笔记，并可以预排版试题篮。

整个程序就是一个文件：**`拾萃.html`**。不需要安装，不需要联网。

## 开始使用

1. 下载 `拾萃.html`（点开文件后，点右上角的下载按钮）。
2. 在“文稿”里新建一个空文件夹，例如“拾萃数据”。
3. 用 **Chrome 或 Edge** 打开 `拾萃.html`，点“选择数据文件夹”，选中刚才新建的文件夹。

之后每次打开，点“继续使用文件夹”即可。Chrome 可能会询问是否允许访问该文件夹，点“允许”。

> Safari、Firefox 和 iPad 暂不支持读写本地文件夹，无法使用。

## 用独立窗口打开（推荐）

不想每次在浏览器里打开？可以把拾萃做成一个桌面图标，双击后在**独立窗口**中打开：没有标签栏和地址栏，看起来和普通桌面程序一样，任务栏/程序坞里也会单独显示拾萃的图标。功能和数据与在浏览器里打开完全相同。

需要的文件在 `桌面窗口` 文件夹里。请把整个仓库下载下来（绿色 Code 按钮 → Download ZIP），解压后放在一个固定的位置（例如“文稿”），保持 `拾萃.html` 和 `桌面窗口` 文件夹在一起。

**Mac**

1. 打开 `桌面窗口` 文件夹，双击 `macOS-安装拾萃.command`。
2. 完成后会自动打开“应用程序”文件夹，里面有带图标的“拾萃”。双击即可打开；可以把它拖到程序坞，以后从程序坞打开。

如果双击时提示“无法打开”或“无法验证开发者”：右键点 `macOS-安装拾萃.command` → 打开 → 再点“打开”；或者到“系统设置 → 隐私与安全性”，在下方点“仍要打开”。也可以打开“终端”，输入 `bash `（bash 后面有一个空格），把这个文件拖进终端窗口，按回车。

**Windows**

1. 打开 `桌面窗口` 文件夹，双击 `Windows-创建桌面快捷方式.cmd`。
2. 桌面和开始菜单里会出现“拾萃”。双击即可打开；在开始菜单里右键“拾萃”可以固定到任务栏。

如果出现“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”。

**说明**

- 窗口使用电脑上已经安装的 Chrome（优先）或 Edge，不需要另外安装任何东西。第一次用独立窗口打开时，如果没有直接进入题库，点“继续使用文件夹”或重新选中原来的数据文件夹即可，数据不会受影响。
- 窗口大小和位置调整一次后会被记住。
- 之后**不要移动** `拾萃.html`。如果移动了它，在旁边的 `桌面窗口` 文件夹里重新运行一次上面的步骤。更新程序时，直接用新的 `拾萃.html` 替换旧文件即可，桌面图标不用重新创建。
- 请不要同时在浏览器和独立窗口里打开拾萃。

## 数据存放

所有内容只保存在你选定的文件夹里，程序不会读写电脑上的其他位置：

| 文件 | 内容 |
| --- | --- |
| `bank.json` | 全部题目、笔记、tag、试题篮、试卷、回收站和设置 |
| `images/` | 题目和笔记中的图片 |
| `backups/` | 每天第一次打开时的自动备份（保留 14 天），以及导入和升级前的自动备份 |

**备份**：把整个数据文件夹复制到 U 盘或网盘；或在“设置 → 导出完整备份”。

**换电脑**：把数据文件夹复制过去，打开拾萃后选中它。

## 更新程序

1. 关闭正在使用的拾萃页面。
2. 下载新的 `拾萃.html`，替换旧文件。
3. 重新打开即可。数据文件夹不用动，已有的题目不会丢失；如果新版改动了数据格式，会在升级前自动备份。

请不要同时打开两个拾萃页面，否则后保存的会覆盖先保存的内容。

## 主要功能

- **目录**：五本书 → 章 → 节逐级展开，另有“综合专题”可自建专题；侧栏顶部可切换 全部 / 高一 / 高二 / 高三。
- **题型**：判断（支持一题多判）、单选、多选、填空（选中文字“挖空”）、解答、实验；选择题和判断题末尾的（　）自动添加。
- **录题**：截图直接粘贴，上下标、着重号、高亮、常用符号、表格、链接；难度五级并可调难度系数；来源、题号、改编；解析、补充、备注。
- **做错记录**：可标记曾误选/漏选的选项、判错的判断、答错的空，答案区用蓝色标出；做错的题难度默认归为“较难”。
- **tag**：每一节有独立的 tag 库，可借用其他节的 tag，题目会同时出现在那一节并标注“跨节”。
- **知识笔记**：每一节分“题目”和“笔记”两栏。
- **搜索与筛选**：关键词全库搜索（含笔记）、tag、题型、难度、难度系数、来源、状态。
- **批量编辑**：批量设难度、年级、加/去 tag、移动到其他节。
- **试题篮**：按 判断 → 单选 → 多选 → 填空 → 解答/实验 自动分组、连续编号；拖动排序；点击题目查看答案解析；分值与难度分布统计；一键复制到 Word。
- **打印 / 存 PDF**：试题篮直接打印学生卷、答案卷，可选 A4 竖版或 A3 横版两栏、字号、分值、班级姓名栏和解答题作答空白；打印窗口里选“另存为 PDF”即可得到 PDF。
- **试卷**：试题篮可以保存为试卷（名称和考试日期），以后重新打开、修改或打印；每道题标注“已用于几份试卷”，可以筛选“用过的 / 没用过的”。
- **查重**：录入新题或导入题目时，如果题库里已有文字高度相似的题，会提示出来，可以选择跳过或仍然保存。
- **回收站**：删除的题目和笔记先放进回收站，保留 30 天，可以在“设置 → 回收站”里恢复。

## 分享给他人

只需要发送 `拾萃.html`，对方打开后会得到一个空题库。若要连同题目一起分享，在“设置 → 导出完整备份”，对方在“设置 → 导入文件”中导入即可。

## 仓库内容

- `拾萃.html`：程序本体。
- `桌面窗口/`：让拾萃在独立窗口中打开的桌面图标创建程序（Mac / Windows）和图标文件。
- `tools/word-import/`：把按固定格式整理的 Word 题目文档转换为导入文件的脚本，见该目录下的说明。

本仓库只存放程序，不包含任何题目数据。
