# 拾萃 · 高中生物好题本

一个在自己电脑上使用的高中生物好题整理工具：按人教版（2019）必修1 – 选择性必修3 的目录整理题目和知识笔记，记下学生（或自己）做错的地方，再把题目选进试题篮，导出成 Word 或 PDF 试卷。

整个程序就是一个文件 **`拾萃.html`**，不用安装，平时使用不需要联网（只在检查新版本时联网，只读取版本信息，不上传任何题目数据）。目前只支持 Mac 上的 **Chrome** 浏览器。

## 第一次使用

1. **下载程序**：在本页上方的文件列表里点开 `拾萃.html`，再点右上角的下载按钮（↓）。
2. **放到固定位置**：把下载好的 `拾萃.html` 从“下载”文件夹移到一个以后不会动的地方，例如“文稿 / 拾萃”。以后在线更新会替换这个位置的文件。
3. **新建数据文件夹**：在“文稿”里再新建一个空文件夹，例如“拾萃数据”，题目和图片都会存在这里。
4. **用 Chrome 打开**：在 `拾萃.html` 上点右键 → “打开方式” → “Google Chrome”（Mac 默认会用 Safari 打开，Safari 无法使用）。也可以把文件直接拖进 Chrome 窗口。
5. **选择数据文件夹**：点“选择数据文件夹”，选中第 3 步新建的文件夹；Chrome 询问是否允许访问时点“允许”。

以后每次打开 `拾萃.html`，点“继续使用文件夹”即可。可以把它加入 Chrome 书签，方便下次打开。

请不要同时打开两个拾萃页面，否则后保存的会覆盖先保存的内容。

## 怎么用

打开后首先看到的是**工作台**：录入新题、写笔记、搜索、试题篮、整卷、试卷存档、导入、导出备份、回收站都能一键打开，还能看到待处理的题和最近录入的题。点顶部的“工作台”或左上角“拾萃”随时回到工作台。

一个常见的流程：

1. **录题**：在左侧目录里选到某一节，点“录入新题”。截图可以直接粘贴进去；选好题型、答案、难度，写上解析和来源。
2. **记下做错的地方**：录题时可以标出误选/漏选的选项、判错的判断、答错的空，它们只在答案区用蓝色标出，题干里不显示答案。做错的题难度默认归为“较难”。
3. **打 tag、写笔记**：每一节有自己的 tag，可以借用其他节的 tag（题目会同时出现在那一节）。每一节还有“笔记”栏。
4. **找题**：用搜索和筛选按关键词、tag、题型、难度、来源、“曾做错”等找题。
5. **组卷**：勾选“选入试题篮”，在试题篮里拖动排序、设分值，保存为试卷；再点“导出试卷”得到 Word 文档或 PDF。

## 主要功能

- **目录**：五本书 → 章 → 节，另有自建的“综合专题”；侧栏顶部可切换 全部 / 高一 / 高二 / 高三。
- **题型**：判断（可一题多判）、单选、多选、填空（选中文字点“挖空”）、解答、实验。
- **录题工具**：粘贴截图、上下标、着重号、高亮、常用符号、表格；难度五级、难度系数、来源、题号、改编、解析、补充、备注；录入时自动提示题库里的相似题（查重）。
- **批量编辑**：批量设难度、年级、加/去 tag、移动到其他节。
- **试题篮与试卷存档**：按题型自动分组、连续编号，统计分值和难度分布；保存的试卷可以重新打开修改，每道题会标出“已用于几份试卷”。
- **整卷**：把一整份外校试卷录入或导入进来，按原卷顺序完整查看（可加“一、单项选择题”等大题标题），每道题的样子和题库里的一样。整卷里的题不进题库，看中哪道点“收进题库”，选好节和 tag 即可。
- **导出试卷**：Word（.docx，可在 Word / WPS 里继续修改）或打印 / 存 PDF；“标准”“测验”“作业”三种版式，A4 竖版或 A3 横版两栏；答案可以不带、附在卷尾、写在每题后（教师用卷）或只导出答案。
- **回收站**：删除的题目、笔记和整卷保留 30 天，可在“设置 → 回收站”恢复。

## 数据存放和备份

所有内容只保存在你选定的数据文件夹里：

| 文件 | 内容 |
| --- | --- |
| `bank.json` | 全部题目、笔记、tag、试题篮、试卷、整卷、回收站和设置 |
| `images/` | 题目和笔记里的图片 |
| `backups/` | 自动备份：每天第一次打开时（保留 14 天）、导入和升级前、在线更新前的旧版程序 |

- **备份**：把整个数据文件夹复制到 U 盘或网盘，或者点“设置 → 导出完整备份”。
- **换电脑**：把 `拾萃.html` 和数据文件夹一起复制过去，打开后选中数据文件夹。
- **分享给同事**：只发 `拾萃.html`，对方得到的是空题库；要连题目一起分享，就发“导出完整备份”得到的文件，对方在“设置 → 导入文件”里导入。

## 更新程序

拾萃打开几秒后会自动检查一次有没有新版本（开着的话每 6 小时再查一次）。有新版时右下角会出现提示，点“去更新”就到“设置 → 程序更新”，看过更新内容后点“下载并更新”，完成后拾萃会自动重新打开。点“以后再说”则这个版本不再提示。

也可以随时在“设置 → 程序更新”里点“检查更新”。不想自动检查，可以在那里取消勾选“打开拾萃时自动检查新版本”。

- 第一次更新时，要在弹出的窗口里选中正在使用的 `拾萃.html`（设置页上写着它的位置），Chrome 询问是否允许修改时点“允许”。之后就不用再选了。
- 更新**只替换 `拾萃.html` 这一个文件**：数据文件夹里的题目、图片不受影响，电脑上的其他文件（包括你自己保存的说明）也不会被改动。旧版程序会先备份到数据文件夹的 `backups` 里。
- GitHub 连不上时会自动改用国内加速地址；下载的文件必须通过校验才会替换。
- **没有网络时**：把新版 `拾萃.html` 拷到电脑上，在“设置 → 程序更新”点“选择新版 拾萃.html 更新”。也可以关掉拾萃，直接用新文件替换旧文件。

设置页“程序更新”里能看到当前版本号。版本号的第一位数字只在重大更新时改变，小功能更新改中间的数字（例如 v2.7.0 → v2.8.0），极小的改动只改最后一位（例如 v2.7.1）。每个版本改了什么，见 [更新记录.md](更新记录.md)。这份使用说明会随新版一起更新，以本页为准。

## 仓库内容

- `拾萃.html`：程序本体。
- `latest.json`、`更新记录.md`：在线更新读取的版本信息和更新内容。
- `tools/word-import/`：把按固定格式整理的 Word 题目文档转换为导入文件的脚本，见该目录下的说明。

本仓库只存放程序，不包含任何题目数据。
